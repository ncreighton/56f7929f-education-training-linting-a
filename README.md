# Education & Training Linting and Best Practices Enforcer VS Code Extension

> Custom rules, auto-fix, inline warnings, and team config sharing for Education & Training code. Catches Education & Training-specific bugs generic linters miss.

## Features

- Core functionality

## Installation

### From VS Code Marketplace
1. Open VS Code
2. Press `Ctrl+P` (or `Cmd+P` on Mac)
3. Type `ext install digitalforge.56f7929f`
4. Press Enter

### From VSIX file
1. Download the `.vsix` file
2. In VS Code: `Extensions > ··· > Install from VSIX`
3. Select the downloaded file

## Usage

Press `Ctrl+Shift+P` and search for `Education & Training Linting and Best Practices Enforcer VS Code Extension` to see all available commands.

**Keyboard shortcut:** `Ctrl+Shift+Alt+A` (or `Cmd+Shift+Alt+A` on Mac)

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `56f7929f.enabled` | `true` | Enable/disable the extension |
| `56f7929f.autoRun` | `false` | Auto-run on file open |
| `56f7929f.logLevel` | `"info"` | Log verbosity |

## Requirements

- VS Code 1.74.0 or higher
